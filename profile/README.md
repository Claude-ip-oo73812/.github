<p>第三个坑是不做归属核验。地址拿到了就直接用，从来不看实际出口落在哪。等到发现问题，可能已经跑了很久，数据要全部重来。</p>

<p>第四个坑是会话标识共用。多个进程用同一个会话标识，请求被分到不同出口，状态忽有忽无，看起来像随机故障。</p>
